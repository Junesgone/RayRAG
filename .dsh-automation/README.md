# 工作日常规自动化（DSH Schedule）

由本会话于 2026-11-20 创建，共 4 个定时任务（Asia/Shanghai，周一至周五）：

| 时间 | 动作 | 说明 |
| --- | --- | --- |
| 08:00 | 暂停 | 暂停所有已开启的计划任务（排除本自动化 4 个任务），记录任务与会话 ID |
| 12:00 | 恢复 | 恢复所有未恢复批次中的任务，并标记 restored |
| 14:00 | 暂停 | 同上 |
| 18:00 | 恢复 | 同上 |

- 每次执行先用 web_search 判定当天是否工作日（含法定节假日与调休）；非工作日直接跳过，不做任何操作。
- 本自动化 4 个任务的指令都含标记 `【工作日常规自动化】`，暂停逻辑据此排除自身，避免“暂停后再也无法恢复”。
- 暂停/恢复记录保存在 `paused-tasks.json`：batchId、action、restored、tasks（id / title / sessionId）。
- 通知语：暂停为“完成这一轮后暂停当前任务”，恢复为“继续当前任务或目标。”。

## 管理

- 查看：侧栏“自动化任务”页面，或在会话中调用 `schedule_list`。
- 停止：在自动化任务页面删除 4 个任务（暂停/恢复各两个）。
- 限制：DSH 计划任务可暂停/恢复；普通会话与子代理没有暂停接口，跨会话消息也只能投递到本会话或 subagent 树。
